# TechStore — Полное описание проекта

## Стек технологий

### Backend
- **Node.js + Express + TypeScript**
- **PostgreSQL 17** (локально: `C:\Program Files\PostgreSQL\17\`)
- **Prisma ORM v5.22** 
- **JWT** (access 15m + refresh 7d с ротацией)
- **multer v2** для загрузки файлов
- **bcryptjs, zod, cors, dotenv**

### Frontend
- **Next.js 16.2.6** (App Router, Turbopack в dev, webpack в prod)
- **TypeScript + Tailwind CSS v4.3**
- **Zustand** (persist) — auth + cart store
- **Axios** с interceptors (авторефреш по 401)
- **react-hot-toast**
- **Шрифты: Inter (тело) + Montserrat (заголовки)** — оба с кириллицей через `next/font/google`

## Деплой на Render

### Адреса
- **Frontend:** https://techstore-web-kd1a.onrender.com
- **Backend:** https://techstore-api-9evw.onrender.com
- **GitHub:** https://github.com/xxxSKYFLYxxx/techstore

### Важно для Render
- Backend и Frontend задеплоены с **pre-built артефактами** (`dist/` + `.next/`)
- При каждом изменении нужно пересобирать локально и пушить
- Render использует: `npm install` → `npm start` (уже собранный код)
- База данных: Render PostgreSQL (бесплатный, истекает каждые 30 дней)
- Строка подключения: internal URL (`dpg-...` без region suffix)
- Ограничение: free tier засыпает после 15 мин простоя (cold start 30-60с)

### Workflow деплоя изменений
```powershell
cd C:\Claude_project\techstore\backend
npm run build   # пересобрать TypeScript

cd C:\Claude_project\techstore\frontend
$env:NEXT_PUBLIC_API_URL = "https://techstore-api-9evw.onrender.com/api"
npm run build   # пересобрать Next.js

cd C:\Claude_project\techstore
git add -f backend/dist/ frontend/.next/   # .gitignore требует -f
git add .
git commit -m "Описание изменений"
git push origin main   # Render автодеплоит (GitHub Actions)
```

## Текущие проблемы и Known Issues

### 1. Каталог (catalog/page.tsx)
Файл изменён внешним редактором — содержит устаревшие `text-[13px]` размеры и `bg-zinc-` классы вместо `bg-[#...]`. Нужно обновить до consistent стиля.

### 2. CSS и Tailwind v4 особенности
- `a { color: inherit; }` в globals.css БЕЗ `@layer base` перебивает все color utilities
- **Решение:** всегда помещать базовые стили в `@layer base { ... }`
- Arbitrary values (`text-[15px]`) иногда не генерируются — использовать `style={{ fontSize: 15 }}`
- `text-white` работает только если `a { color: inherit }` в @layer base

### 3. Next.js 16 + Turbopack
- `useSearchParams()` внутри Suspense в Next.js 16 может бесконечно зависать
- **Решение:** catalog/page.tsx = `"use client"` без Suspense (useSearchParams напрямую)
- При деплое: нельзя `npm run build` на Render (память ограничена), нужен pre-built `.next/`

### 4. Изображения
- 19/20 товаров с реальными фото
- **Sony WF-1000XM5** — фото не найдено нигде (CSS gradient placeholder)
- Samsung S24 Ultra и S24 — теперь разные фото (были одинаковые)
- Sony WH-1000XM5 — маленький файл 35KB, работает но низкое качество

### 5. PostgreSQL на Windows
- Не зарегистрирован как сервис — нужно запускать вручную при каждом перезапуске
- Команда: `& "C:\Program Files\PostgreSQL\17\bin\pg_ctl.exe" start -D "C:\Program Files\PostgreSQL\17\data"`
